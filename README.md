InstaView – Instagram Homepage Clone

About The Project

InstaView is a simple Instagram-inspired homepage built using HTML, CSS, and Bootstrap 5. The project aims to recreate the basic layout and appearance of Instagram.

Features

- Responsive homepage layout.
- Sidebar navigation.
- Stories section with profile images.
- Posts section.
- Like button interaction.
- Follow button interaction.
- Suggested users section.

Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

How To Run

1. Download or clone the project.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Enjoy exploring InstaView!
